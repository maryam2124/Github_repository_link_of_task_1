# Rule-Based AI Chatbot (Python Project)

## Overview
This project is a simple **rule-based chatbot system** built using Python.  
It responds to user inputs based on predefined rules and keyword matching logic.

The chatbot simulates basic conversational abilities such as greetings, small talk, information responses, jokes, and system commands.

## Objective
To design a simple chatbot that:
- Takes user input
- Matches it with predefined responses
- Returns appropriate replies
- Simulates basic human-like conversation

---

## Technologies Used
- Python
- Jupyter Notebook / Google Colab

---

## Project Features

- Rule-based response system using dictionary mapping  
- Greeting and small talk handling  
- AI-related basic Q&A responses  
- Fun interaction (jokes, humor)  
- System commands (exit, bye, quit)  

---

## Workflow

1. User enters input  
2. Input is matched with predefined dictionary keys  
3. If match found → response is returned  
4. If not found → default message is shown
